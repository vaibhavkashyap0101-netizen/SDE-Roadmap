Portfolio projects

Choose a project you can demo in two minutes. Include a README with setup steps, screenshots, sample data and the decisions you made.

Expense Tracker

Add, edit and delete expenses. Filter by month and category, show totals and save entries across reloads.

Test: Empty lists, invalid amounts and a page reload.

Placement Portal

Build job listings, student applications and an admin review screen. Store applications in SQL and filter by status.

Test: Duplicate applications and a student trying to view someone else’s application.

Campus Event Booking

Let students reserve seats and cancel bookings. Add a capacity limit and a dashboard for organisers.

Test: Two people booking the last seat at the same time.

Internships and placements

Prepare your application

Make a one-page résumé. Describe what you built, link your best projects, and add numbers when you can verify them. Track each application and deadline.

Practice technical rounds

Use a 45-minute mock session. Clarify the problem, explain a simple approach, improve it, state time and space complexity, then test with edge cases.

Practice project and HR rounds

Explain one design trade-off and one bug you fixed. Prepare short examples of teamwork, disagreement and learning using Situation, Task, Action and Result.
